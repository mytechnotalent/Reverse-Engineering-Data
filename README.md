# Reverse Engineering Data
Master the art of reverse engineering data and discover how to deconstruct, analyze, and rebuild datasets for deeper understanding and actionable insights.

<br>

## Download & Install Conda [HERE](https://www.anaconda.com/download/success)

<br>

## Create Conda Environment
```bash
conda create --name prod anaconda
conda activate prod
conda update --all
```

<br>

## Repository Structure
```
data/      datasets (CSV files, Tiny Shakespeare, downloaded image datasets)
models/    trained model artifacts (.pt, .onnx, .pkl)
outputs/   generated outputs such as the Kaggle submission
*.ipynb    the 30 notebooks, numbered 00 through 29
```
